This project is a single-page accessible personal portfolio website built using HTML5 and CSS3.

It includes:

Semantic HTML5 structure like header, nav, main, section, article, and footer.
Accessible navigation with keyboard support and ARIA labels.
SEO-friendly title and meta description.
About, Skills, Projects, and Contact sections.
A keyboard-friendly and screen-reader-friendly contact form.
Responsive design for mobile and desktop.
WCAG-focused colors, focus indicators, and reduced-motion support.
